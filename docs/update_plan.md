# 更新分支工作约定

paper-reproduction 分支固定已验收的历史算法。numerical-updates 新增更新接口，不覆盖历史结果。

已确认修复：强子虚部缺少逆精细结构常数、双 pion 换算常数笔误、轻子对数消减误差。新计算统一使用同一精细结构常数和截面单位。

数值处理：ISR 线性卷积使用三角解代替固定次数近似，显式检查负解和前向残差；VP 使用分段线性截面的解析主值积分代替将奇点元素置零，并按容差迭代。保留独立数值积分与网格细化检查。

平滑：以能量阈值配置，默认仅在 ISR 输入截面上从 $10.6659\,\mathrm{GeV}$ 开始普通 LOWESS，不在 VP 再平滑。比较阈值变化、邻域宽度及相同起点二次平滑。平滑是估计方法选择，不能靠收敛证明唯一正确。

误差：同一 toy 连续经过 ISR、VP、Born 比值，保留能点协方差及两个因子的相关性；中心值报告名义输入，另列 toy 均值与非线性偏移。误差汇总排除首个名义样本。不将负解删除、截为零或把未量化的理论误差当作已包含。

结果只有满足已声明的残差/方法/细化检查，才可接受为给定输入模型下的数值结果。物理先验与完整理论系统误差未确定时明确记录限制。
