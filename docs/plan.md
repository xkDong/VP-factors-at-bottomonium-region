# 复现范围与计划

本包锁定 arXiv:2002.09838 / CPC 最终附录的逆 ISR 因子及其误差；该初始范围已扩展到 VP，见 vp_plan.md；共振拟合仍不在本包已验证范围内。

采用大仓库 R_b/matlab/codes1 中经历史结果核实的 source-faithful 基准：
1. 导出计算实际使用的能点、截面及四类误差，保留历史统计/总误差抽样输入。
2. Julia 实现普通 LOWESS、以能量平方插值的解析积分、逐能点 30 状态迭代。
3. 分别计算统计抽样逆 ISR 均值、总误差抽样标准差，逐点核对 CPC 表。
4. 实现新种子抽样入口，并检查历史模式、迭代敏感性、输入完整性及独立运行。

已知限制：历史 MATLAB 随机种子不可恢复；重现完全相同的有限样本均值必须使用保存的抽样输入。新种子产生统计等价而非逐位相同结果。历史 30 状态是复现约定，不能自动称为收敛极限。不对齐结果而调整参数。
