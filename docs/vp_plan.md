# VP 复现计划与约定

目标：在现有独立包中复现 CPC 附录 VP 均值及误差。精确来源已定位到 vp_smo_tot_err_0320.mat；两者均来自总误差抽样，不能照搬 ISR 的统计均值/总误差标准差拼接方式。

1. 导出实际输入 Rpdg、Rbes、未平滑 Rbb，保留网格及源文件哈希。
2. 移植普通 LOWESS、Newenergy 的五等分网格、PIL、PIH、pQCD 与迭代更新。
3. 先比较名义输入、所有样本的平滑和最终 VP，再核对附录均值与样本标准差。
4. 检查历史积分约定和迭代敏感性，保留历史参数，不为了改善数值精度而静默改变附录复现基准。

注意：当前 vp_iterate.m 已被改成 smoothing spline，需以历史保存结果和 vp_iterate_sta.m 的普通 LOWESS 路径交叉验证。历史算法的梯形积分将奇点处被积函数置零；这与解析主值积分不是同一离散算法。
