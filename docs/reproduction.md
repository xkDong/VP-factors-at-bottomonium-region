# 当前验证状态

本包已用 Julia 1.12.6 验证：合成数据测试 $15/15$、历史名义结果测试 $2/2$ 通过，包括缓存积分与直接原函数路径、归一化不变性、LOWESS 常数和线性函数保持性、抽样可复现性、二进制输入读取。

## 完整历史重放

统计和总误差两组各 $10000$ 个随机截面输入已用 Julia 从头平滑并反演。每组包含阈值在内的 $210$ 个能点；与原 MATLAB 保存因子逐样本比较，共检验 $4200000$ 个因子。

| 对照 | 最大绝对差 |
| --- | ---: |
| 统计样本全部逆因子 | $1.03\times10^{-11}$ |
| 总误差样本全部逆因子 | $1.05\times10^{-11}$ |
| 附录 $209$ 点中心值 | $8.39\times10^{-12}$ |
| 附录 $209$ 点误差 | $2.57\times10^{-13}$ |

逐点输出见 [附录对比](../results/historical/appendix_comparison.csv)，机器可读检查见 [历史验证报告](../results/historical/validation.toml)。前期有偏差的 $10.6128$、$10.6458$ 和 $10.9077\,\mathrm{GeV}$ 均已对齐。

## 新种子与迭代敏感性

新种子模式使用统计种子 $2020$、总误差种子 $2021$，两组各 $10000$ 个样本，运行完成。它采用相同的抽样分布和计算约定，但不沿用 MATLAB 的历史随机数序列。与附录的中心值最大绝对差为 $0.00354$，误差最大绝对差为 $0.00201$。此项仅验证新种子入口及直接/缓存路径一致性，不将其称作逐点精确复现，也未对该单组随机种子做完整统计覆盖率检验。

名义输入从 $30$ 增至 $60$ 状态时，逆因子最大绝对变化为 $0.001671$。因此本包验证的是历史算法及参数的再现，不宣称历史迭代已达到无限迭代极限。

原项目与原始 MATLAB 文件均未修改。程序只依赖标准库及包内数据；没有在运行时读取旧项目或外置硬盘。尚未上传 GitHub。
