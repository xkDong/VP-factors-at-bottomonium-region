## 收敛与独立方法

历史 ISR 在同一旧卷积核下，与精确线性解的最大ISR 修正因子偏差：

| 状态数 | 最大绝对差 |
| --- | ---: |
| $30$ | $1.69\times10^{-3}$ |
| $60$ | $1.57\times10^{-5}$ |
| $120$ | $1.46\times10^{-9}$ |
| $240$ | $3.77\times10^{-15}$ |

新版 ISR 前向残差约 $4.44\times10^{-16}\,\mathrm{nb}$，矩阵条件数约 $2.43$；独立软积分变换检查差异约 $1.30\times10^{-14}\,\mathrm{nb}$。

生产 VP 使用测量网格细化 $20$ 倍、背景细化 $2$ 倍、上限 $200\,\mathrm{GeV}$、尾部步长 $0.125\,\mathrm{GeV}$。网格、背景、尾步长、上限分别变化，相对于更细设置的名义 VP 变化保守相加约 $5.16\times10^{-7}$，低于声明的 $10^{-6}$ 绝对数值精度目标。这是经验细化检查，不是严格区间误差上界，也不是高能模型误差。

独立主值积分在五个代表性能点使用不同积分表示，$\Pi$ 差异约 $1.24\times10^{-14}$。全样本 VP 固定点残差小于 $2\times10^{-13}$，通常至多 $7$ 轮。

证据：[验收记录](../results/updates/acceptance.toml)、[网格检查](../results/updates/grid_convergence.csv)、[独立积分](../results/updates/independent_methods.toml)。

## 误差分类

大仓库 sta 和 tot 输入文件的 Rpdg、Rbes 数组逐字节相同。因此原“stat”运行已混入相同的背景误差，不能称作所有来源的纯统计误差。源文件及数组哈希见 data/vp/stat_provenance.json；不重复存储相同数组。

新版分别报告：

- 底区统计分量：只改变底区统计样本，背景固定名义值。
- 背景输入分量：底区固定名义谱，只改变低能及粲区保存样本。
- 全部输入误差：底区总误差与背景输入共同传播。

没有强行以方差相减定义系统协方差，也未裁剪负特征值。当前背景样本不能可靠拆成统计与系统分量，不能凭文件名补造该信息。

以下 0.526% 检查对应原先求解器光滑谱，不是后来原始数据乘回定义的结果。Born 使用逐样本比值，保留 dressed 与 VP 的相关性。忽略相关性时，独立误差近似对 Born 标准差的最大相对差约 $0.526\%$。协方差正半定性已检验，允许浮点舍入级负特征值。

误差统计使用 $9999$ 个随机样本，排除首个名义样本，并以不重叠批次检查 MC 精度。两个新种子只重新抽取底区输入，背景仍为同一组保存样本；不是所有实验输入均独立重抽的两次完整实验。原背景相关性保留，不额外推断实验间共同误差。

## 负估计与平滑

名义 dressed $R_b$ 全部为正，最小约 $0.0483$。总误差样本中 $773$ 个能点的线性反演估计小于零：

| 能量（GeV） | 负值样本数 |
| --- | ---: |
| $10.6018$ | $10$ |
| $10.6063$ | $729$ |
| $10.6128$ | $14$ |
| $10.6458$ | $20$ |

这些是带噪测量的线性估计，不是负物理截面。全部保留，避免截零和删样本偏差。历史乘法迭代隐含非负性，其有限迭代也有正则化作用；不能把两者差异都归为浮点误差。若要求严格非负物理谱，应在前向折叠模型中拟合并声明先验，而非静默修剪。

单次平滑是声明的模型选择，不是唯一正确设置。将起点移至 $10.6613\,\mathrm{GeV}$，名义 VP 最大相对变化约 $0.0192\%$；同起点二次平滑约 $0.00653\%$。跨度变化见 [敏感性表](../results/updates/smoothing_sensitivity.csv)。这些变化未作为独立高斯误差加入协方差。

## 适用范围

pQCD 参数和阈值模型、窄共振参数、实验外部校准、相关性重建及平滑/插值模型偏差尚未完全量化。原有限阶 pQCD 表达式保留，不宣称使用了现代阈值匹配求解。

新版名义 VP 相对附录最大变化约 $0.165\%$，其中还包括名义输入与样本均值两种中心值定义的区别。正式物理结论须另行纳入上述模型系统项；本次验收限定于明示输入模型、线性估计和数值精度。
